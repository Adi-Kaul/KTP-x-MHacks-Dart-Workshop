# KTP x MHacks Dart Workshop

A trimmed-down version of the profile screen from the KTP app that runs in DartPad. You work through the challenges in the file to make the profile your own and learn some Dart and Flutter along the way.

## How to start

1. Open [ktp_profile_dartpad.dart](ktp_profile_dartpad.dart) and copy everything.
2. Go to [dartpad.dev](https://dartpad.dev), delete what's there, and paste it in.
3. Hit Run and start with Challenge 1.

Instructions, hints and answers are all in the file.
